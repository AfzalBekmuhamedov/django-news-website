News Website — Django News Platform

News Website is a Django-based web application designed for publishing and browsing news articles.

The project follows a structure similar to the Django marketplace project, with additional functionality for user comments.

Purpose

The purpose of this project is to demonstrate how a news platform can be developed using Django.

Users can browse news articles, search for content, explore categories, and interact with articles through comments.

Features

- User Registration
- User Login
- User Logout
- News Categories
- News Search
- News Detail Pages
- Comments
- Article Management
- Django Admin Panel

News Discovery

Users can explore news through different categories and search for specific articles.

Each article has its own detail page containing the article information.

Comments

Users can interact with news articles through the comment section.

Authentication

The project includes:

- Registration
- Login
- Logout

Administration

News articles and other platform data can be managed through Django Admin.

Technologies

- Python
- Django
- HTML
- Bootstrap
- Database
